# 아르스킨 업무보고 웹앱

Google 시트(월간 탭)를 데이터베이스로 쓰는 정적 웹앱. 일간 보고서 조회·수정·추가, 타임블로킹, 콘텐츠 캘린더 연동, 인쇄(Ctrl+P)용 레이아웃을 제공한다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html`, `styles.css`, `app.js` | 웹앱 (빌드 없음, 정적 호스팅) |
| `config.js` | Apps Script URL / 키 / 이름 / 표시 일수 |
| `apps-script/Code.gs` | Google Apps Script 백엔드 (시트 읽기·쓰기) |

### 시트 구조 (월간 탭)

`아르스킨 일일보고 시트`에 월별 탭 `YYYY-MM` 하나에 한 행 = 한 항목.

```
id | 날짜 | 구분 | 열 | 상태 | 내용 | 시작 | 종료 | 수정시각
```

- 구분: `메모` `회의`(열=월~금/일정) `마케팅공통` `주간고정` `데일리고정` `배치예정` `변동업무` `릴스업무`(열=L/R) `원장님완료`(열=요일) `원장님리스트`(열=원개블/그외/릴스촬영) `원장님숙제`(열=영어/영상) `타임라인`(시작/종료=HH:MM)
- 상태: ⭕ 완료 · ▶️ 진행 중 · 🔷 시작 전 · ⏸️ 보류 · 🔄 반복
- 기존 일자별 탭(261014~261102)은 `2026-10`, `2026-11` 탭으로 변환해 두었다. 옛 탭은 그대로 남아 있으니 확인 후 삭제하면 된다.

## 설치

1. **Apps Script 배포**
   - `아르스킨 일일보고 시트` → 확장 프로그램 → Apps Script → `apps-script/Code.gs` 내용 붙여넣기
   - `API_KEY` 값을 바꾸고(`config.js`와 동일하게), 배포 → 새 배포 → 유형: 웹 앱 / 실행: 나 / 액세스: **모든 사용자**
   - 배포 URL을 `config.js`의 `API_URL`에 넣는다. (현재 들어있는 URL은 로그인 페이지로 넘어가므로 그대로는 동작하지 않는다.)
2. **GitHub Pages**: 저장소 Settings → Pages → Branch `main` / root. 또는 아무 정적 호스팅.
3. 모바일에서도 같은 주소로 접속하면 된다 (하단 탭 + 보고서/타임라인 전환).

## 사용

- 상단 날짜 칩: 당일 기준 최근 5근무일. 비어 있는 날은 **전일 가져오기**로 직전 보고서의 미완료 항목을 복사한다(⭕ 완료·타임라인 제외, 데일리 고정업무는 🔷로 초기화).
- 상태 아이콘 클릭 → 순환 변경. 글자 클릭 → 바로 수정. 각 칸 아래 입력창에서 Enter → 추가.
- **완료 접기**: 완료 항목을 접어 변동업무가 세로로 길어지는 것을 막는다(인쇄에는 전부 나옴).
- 타임라인: 빈 곳을 마우스로 드래그해 블록 생성, 블록 드래그로 이동, 클릭으로 수정/삭제. 모바일은 `+ 블록`.
- 인쇄(Ctrl+P): 일간 보고서만, 시트와 같은 좌/우 표 형태로 행이 잘리지 않게 출력된다.
- 콘텐츠 캘린더: `아르스킨 인스타 관리` 시트의 `컨텐츠 캘린더` 탭을 읽어 월간 보기로 표시하고, 일간 보고서 하단에 그날 발행분을 보여준다(읽기 전용).
