# 아르스킨 업무보고 웹앱

Google 시트(월간 탭)를 데이터베이스로 쓰는 정적 웹앱. 일간 보고서 조회·수정·추가, 타임블로킹, 콘텐츠 캘린더 연동, 인쇄(Ctrl+P)용 레이아웃을 제공한다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html`, `styles.css`, `app.js` | 웹앱 (빌드 없음, 정적 호스팅) |
| `config.js` | Apps Script URL / 키 / 이름 / 표시 일수 |
| `apps-script/Code.gs` | Google Apps Script 백엔드 (시트 읽기·쓰기) |

### 시트 구조 (월간 탭)

`아르스킨 일일보고 시트`에 월별 탭 `YYYY-MM` 하나에 한 행 = 한 항목.

```
id | 날짜 | 구분 | 열 | 상태 | 내용 | 시작 | 종료 | 수정시각
```

- 구분: `메모` `회의`(열=월~금/일정) `마케팅공통` `주간고정` `데일리고정` `배치예정` `팔로업` `변동업무` `릴스업무`(열=L/R) `원장님완료`(열=요일) `원장님리스트`(열=원개블/그외/릴스촬영) `원장님숙제`(열=영어/영상) `타임라인`(시작/종료=HH:MM)
- 상태: ⭕ 완료 · ▶️ 진행 중 · 🔷 시작 전 · ⏸️ 보류 · 🔄 반복
- 기존 일자별 탭(261014~261102)과 `11월 1주차/2주차 전성환 일일보고` 시트(261103~261112)는 `2026-10`, `2026-11` 탭으로 변환해 두었다. 옛 탭·시트는 그대로 남아 있으니 확인 후 삭제하면 된다.

## 설치

1. **Apps Script 배포**
   - `아르스킨 일일보고 시트` → 확장 프로그램 → Apps Script → `apps-script/Code.gs` 내용 붙여넣기
   - `API_KEY` 값을 바꾸고(`config.js`와 동일하게), 배포 → 새 배포 → 유형: 웹 앱 / 실행: 나 / 액세스: **모든 사용자**
   - 배포 URL을 `config.js`의 `API_URL`에 넣는다. (현재 들어있는 URL은 로그인 페이지로 넘어가므로 그대로는 동작하지 않는다.)
2. **GitHub Pages**: 저장소 Settings → Pages → Branch `main` / root. 또는 아무 정적 호스팅.
3. 모바일에서도 같은 주소로 접속하면 된다 (하단 탭 + 보고서/타임라인 전환).

## 사람 추가 / 시트 연결

일간 보고서 하위 메뉴는 `config.js`의 `PEOPLE` 순서(박선희 → 전성환 → 양욱정)로 나온다.
시트를 연결하려면 두 곳에 같은 이름으로 시트 ID를 넣고 Apps Script를 **새 버전으로 재배포**한다.

1. `apps-script/Code.gs`의 `REPORT_SHEETS` (서버 쪽 허용 목록)
2. `config.js`의 `PEOPLE[].sheet` (비어 있으면 "연결 대기"로 표시되고 요청을 보내지 않음)

배포한 Apps Script 계정이 각 시트의 편집 권한을 가지고 있어야 한다.

## 공통 캘린더 · 공통 업무

모든 사람의 일간 보고서 맨 위에 같은 주간 캘린더(상단 고정)와 공통 업무가 나온다.
데이터는 `아르스킨 공통` 시트의 월간 탭에 `구분=일정`(시작/종료/작성자=열) · `구분=공통업무`로 저장되고, 60초마다·창 전환 시 다시 불러와 서로 연동된다.

## 로고

저장소 루트에 `logo.png`를 넣으면 사이드바에 표시된다. 없으면 "아르스킨" 글자로 보인다.

## 사용

- 상단 날짜 칩: 당일 기준 최근 5근무일. 비어 있는 날은 **전일 가져오기**로 직전 보고서의 미완료 항목을 복사한다(⭕ 완료·타임라인 제외, 데일리 고정업무는 🔷로 초기화).
- 상태 아이콘 클릭 → 순환 변경. 글자 클릭 → 바로 수정. 각 칸 아래 입력창에서 Enter → 추가.
- **완료 접기**: 완료 항목을 접어 변동업무가 세로로 길어지는 것을 막는다(인쇄에는 전부 나옴).
- 타임라인: 빈 곳을 마우스로 드래그해 블록 생성, 블록 드래그로 이동, 클릭으로 수정/삭제. 모바일은 `+ 블록`.
- 인쇄(Ctrl+P): 일간 보고서만, 시트와 같은 좌/우 표 형태로 행이 잘리지 않게 출력된다.
- 콘텐츠 캘린더: `아르스킨 인스타 관리` 시트의 `컨텐츠 캘린더` 탭을 읽어 월간 보기로 표시하고, 일간 보고서 하단에 그날 발행분을 보여준다(읽기 전용).

공통업무 및 회의 일정은 공통 시트로 통합했습니다. 개인 보고서와 인쇄 화면에는 마케팅 공통/회의 입력란을 표시하지 않으며 전일 가져오기도 제외합니다. 공통 업무는 동일 내용의 최신 상태를 표시하고, 원본 날짜별 이력은 공통 시트에 보존합니다. 회의 시간 미정 항목은 시간을 비워 두며 날짜 미정 항목은 캘린더 하단 확인 목록에 표시합니다.

## 프로젝트 진행도

변동업무의 `+ 하위 업무`를 누르면 프로젝트로 전환됩니다. 하위 업무를 입력하고 완료 체크하면 보고서 상단과 프로젝트 카드에 완료 수/전체 수 및 진행 바가 표시됩니다. 하위 업무 완료 비율에 따라 상위 업무 상태가 시작 전·진행 중·완료로 바뀝니다. 데이터는 같은 개인 시트에 `프로젝트`(열=상위 업무 ID), `하위업무`(열=상위 업무 ID)로 저장됩니다. 전일 가져오기는 미완료 프로젝트의 하위 업무를 새 상위 ID에 연결해 복사합니다.

## 콘텐츠 스튜디오

기존 캘린더 앱 iframe을 콘텐츠 스튜디오로 통합했습니다. `content-hub.html`과 `content-hub.js`가 캘린더, 6개 채널 필터, 상세 게시물, 분석, 영상 기획을 표시합니다. 화면은 처음 열 때만 읽으며 과거 스냅샷이나 Instagram 접근 토큰을 포함하지 않습니다. Instagram 미리보기는 사용자가 요청할 때만 생성합니다.

콘텐츠 API 업데이트는 [연결 안내](apps-script/CONTENT-SETUP.md)를 따르세요. 업데이트 전에는 기존 `calendar` API의 실제 발행 일정을 표시하고, 데이터가 없는 분석·기획 기능은 비활성화합니다. 업데이트 후 새로고침하면 자동 활성화됩니다. 수동 새로고침은 서버 캐시를 건너뛰며 자동 확인은 60초 간격입니다. 모바일에서는 화면 맨 위에서 85px 이상 아래로 당겼다 놓으면 새로고침합니다. 편집 중에는 새로고침을 미룹니다.

마케팅 공용 캘린더는 월~금 기준 주간/월간을 전환하고, 모바일에서는 하단 핸들 버튼으로 접거나 펼칩니다. 일정 내용은 잘라내지 않고 줄바꿈하며, 달력 탐색은 개인 보고서 날짜와 독립적입니다. 전체 월간 일정도 조회합니다.

API v4에는 Script Properties에 등록한 Instagram 토큰으로 신규 게시물을 수집하는 함수와 트리거 설치 함수가 포함됩니다. 설정·배포 방법과 제한은 `apps-script/CONTENT-SETUP.md`를 참고하세요.

## 월간 매출표

메뉴 순서는 콘텐츠 스튜디오 → 일간보고서 → 월간 매출표입니다. 초기 화면은 콘텐츠 스튜디오이며 사이드바 상태 범례는 제거했습니다. `revenue-hub.js`는 원본 월간요약 기준의 총금액·보고 건수·일별/누적 추이·결제수단·국가별 구성·담당자별 집계·시술 포함 건수를 표시합니다. 시술 중복 집계, 보고 건수와 고객 수의 차이, 업셀 기준을 화면에 명시합니다. 실제 매출 데이터는 정적 파일에 포함하지 않고 POST API로 조회합니다.

별도 조회키 `REVENUE_VIEW_KEY`를 Script Properties에 설정한 뒤 API v5를 새 버전으로 배포해야 합니다. 조회키는 공개 config.js나 브라우저 저장소에 저장하지 않습니다. 접속 중 새로고침하거나 잠그기를 누르면 매출표가 잠깁니다.

## 인쇄 · 메뉴 · 매출 분석 보완

일간보고서는 A4 세로, 사방 10mm 여백으로 출력합니다. 모바일 타임라인을 선택한 상태에서도 인쇄 보고서는 표시되며, 긴 보고서는 A4 여러 장으로 이어집니다. 공통 업무는 내용의 공백과 앞 장식 기호를 무시해 최신 항목을 표시하고, 가용 너비에 따라 최대 3열로 배치합니다. 원본 업무 이력은 보존합니다.

콘텐츠 캘린더·분석·영상 기획 전환은 사이드바 콘텐츠 스튜디오 하위 메뉴에 있으며 모바일에서는 콘텐츠 화면 위에 표시됩니다. 기획 수정 중 전환을 막는 기존 동작과 API 연결 상태에 따른 메뉴 활성화를 유지합니다.

월간요약 분석에는 요일별 기록일 평균, 담당자 합계와 최종 누적 검증을 추가했습니다. API v5 연결 전에는 매출표의 ‘월간요약 CSV 파일로 보기’로 원본 월간요약 탭에서 다운로드한 CSV를 읽을 수 있습니다. CSV 내용은 서버·브라우저 저장소에 저장하지 않으며 새로고침·잠그기로 지워집니다. CSV는 파일 시점 자료이며 자동 동기화되지 않습니다. 합계 검증, 국가별 매출, 시술 포함 건수의 기준은 API 조회와 같습니다.

앱 아이콘은 `assets/arskin-icon.png`, 홈 화면 설정은 `manifest.webmanifest`에 연결되어 있습니다. 아이콘은 사용자 제공 로고 이미지를 참고해 웹용으로 준비했습니다. 이미 홈 화면에 추가한 바로가기는 브라우저 캐시 상태에 따라 다시 추가해야 할 수 있습니다.

## 현재 매출표 연결 방식

매출표는 Google Sheets의 월간요약(gid=1411519381), A1:AF100을 CSV로 직접 조회합니다. 현재 원본의 접근 설정에서 인증 없이 조회되며 브라우저의 교차 출처 요청도 허용됩니다. 공유 설정은 변경하지 않았습니다. 조회키나 Apps Script 재배포는 필요 없습니다. 탭을 처음 열면 자동 조회하며 새로고침으로 최신 수치를 읽습니다. 기존 데이터가 있을 때 갱신에 실패하면 마지막 데이터와 실패 상태를 표시합니다. 원본 접근 설정이 바뀌면 조회 오류를 표시하며 CSV 파일 열기를 사용할 수 있습니다. 위의 API v5/조회키 설정은 이전 연결 방식의 기록입니다.
